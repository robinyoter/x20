About the data

The 2,019 senators come from Wikipedia's former and current senator lists. Birthplaces come from Wikidata and are mapped to the present-day state that contains them, so someone born in colonial Virginia counts as Virginia. "Outside the states" covers foreign countries, U.S. territories and the Panama Canal Zone. A senator counts toward a period if any of their Senate service falls inside it. A few senators represented more than one state and count once for each. State borders: U.S. Census Bureau via the us-atlas package.

Surname origin is a guess from the surname alone and follows only the father's line. Married and anglicized names count as served, so a senator's own heritage can differ from the label.
